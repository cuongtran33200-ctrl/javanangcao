\section*{A. Hướng dẫn cài đặt và chạy chương trình}
\phantomsection
\addcontentsline{toc}{section}{A. Hướng dẫn cài đặt và chạy chương trình}

Yêu cầu JDK 17 trở lên. Giả sử \code{\$jdk} là thư mục JRE chứa
\code{bin/javac.exe} (hoặc \code{javac} đã có trên \code{PATH}).

\begin{lstlisting}[language=bash, caption={Biên dịch và chạy ứng dụng.}]
# 1. Compile all sources into out/
javac -encoding UTF-8 -d out src/vn/edu/dau/bxh/**/*.java

# 2. Start the server (port 5000, 0 = cached thread pool)
java -cp out vn.edu.dau.bxh.server.MayChuBXH 5000 0

# 3. In another terminal, start a viewer
java -cp out vn.edu.dau.bxh.client.KhachXem 127.0.0.1 5000

# 4. In another terminal, start a referee and type commands
java -cp out vn.edu.dau.bxh.client.TrongTai 127.0.0.1 5000

# 5. Run tests (no network needed)
java -cp out vn.edu.dau.bxh.test.TestXepHang
java -cp out vn.edu.dau.bxh.test.TestDongThoi 8 200

# 6. Package as jar
jar --create --file bxh.jar --main-class vn.edu.dau.bxh.server.MayChuBXH -C out .
java -jar bxh.jar 5000 0
\end{lstlisting}

\section*{B. Bảng tự kiểm trước khi nộp}
\phantomsection
\addcontentsline{toc}{section}{B. Bảng tự kiểm trước khi nộp}

Trước khi nộp, tự đánh dấu vào từng ô dưới đây.

\begin{tukiem}
  \item Máy chủ chạy được trên máy khác, không chỉ trên máy của em.
  \item Sáu lệnh giao thức đều chạy đúng trên dữ liệu thử.
  \item Đã chạy \code{TestDongThoi} và không mất trận khi nhiều trọng tài gửi
        đồng thời.
  \item Mã nguồn nằm trên kho \code{git}, lịch sử commit trải đều từ tuần~5.
  \item Có tệp \code{README.md} hướng dẫn cách chạy, đóng gói được thành jar.
  \item Có đủ record, enum, ngoại lệ tự định nghĩa và \code{try-with-resources}
        khi mở tệp và socket.
  \item Mọi hình, bảng đều có chú thích, có nhãn và được nhắc tới trong thân.
  \item Đã khai báo phần dùng công cụ AI trong \code{khai-bao-AI.pdf}.
  \item Đã xoá hết hộp gợi ý, khối nội dung mẫu và sổ tra cứu quy cách trình bày.
\end{tukiem}

nào sót lại không.
\end{luuy}
